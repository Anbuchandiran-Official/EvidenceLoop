EXECUTION PIPELINE

How It Works

Four rigorous verification checkpoints before any answer is retained

01

Deconstruct & Plan

Decomposes questions into explicit subquestions, defines target entities, time periods, and explicit evidence gaps before issuing searches.

02

Parallel Retrieval

Issues targeted web queries, fetches full primary source web pages in parallel, and synthesizes atomic factual claims with exact citations.

03

Independent Audit

An isolated auditor model re-fetches primary sources, verifies exact substring quote provenance, and audits mathematical consistency.

04

Repair & Learn

Attempts one repair per flagged claim. Once re-audited and verified, checking lessons are stored in persistent memory for future research.

SCRUTINY PRINCIPLES

Why Scrutiny Matters

How EvidenceLoop solves the hallucination problem in automated research

“ PROVENANCE

Receipts Over Probabilities

Every claim must cite an exact substring from an independently re-fetched source document. If a sentence cannot be found verbatim in the source text, it is flagged.

“ ISOLATION

Independent Auditor Context

The auditor does not read the analyst's draft reasoning chain. It independently fetches the cited URLs, evaluates the claims against the raw text, and verifies math independently.

“ ACCUMULATION

Persistent Correction Memory

When a claim is repaired (such as distinguishing net additions from gross store openings), the lesson is persisted into memory and applied to future research plans.
